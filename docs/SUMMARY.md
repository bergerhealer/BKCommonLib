BKCommonLib is a Bukkit/Paper plugin library for cross-version Minecraft server development. Use it for server internals
and Bukkit compatibility; packets and entity metadata; interactive map displays; worlds, chunks, blocks, entities, items
and inventories; YAML and NBT data; 3D math; and common plugin utilities such as scheduling, events, commands and permissions.

Main package and recognizable import prefix: `com.bergerkiller.bukkit.common`. Documentation lives in `docs/`; start
with `docs/overview.md`, use `docs/README.md` as the index, and see `docs/glossary.md` for project terms.
